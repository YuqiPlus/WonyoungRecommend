## 初次见面，张元英

张元英 **JANG WONYOUNG / 장원영**，IVE 成员，生日是 **2004 年 8 月 31 日**。

不需要先懂所有梗，也不用补完所有视频。从一首歌、一段舞台、一次笑容开始，慢慢找到你喜欢的那一面。

## 第一次来，从这三个瞬间开始

1. **先听一首歌**：[《LOVE DIVE》官方 MV](https://www.youtube.com/watch?v=Y8JFxS1HlDo)。留意她的镜头，感受从容与灵动。
2. **把镜头留给她**：[《I AM》元英个人直拍](https://www.youtube.com/watch?v=-upaPSCKQeg)。从动作到表情，发现舞台里的小细节。
3. **认识舞台以外的她**：[《1,2,3 IVE》S4 EP.1](https://www.youtube.com/watch?v=fIGHHs5Uuyk)。看看和成员们一起笑的时候，另一种可爱的元英。
